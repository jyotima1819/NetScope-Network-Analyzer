# NetScope — Network Packet Analyzer

## Overview
NetScope is a Python-based network packet analysis and visualization dashboard built using Streamlit.

## Features
- Upload PCAP and PCAPNG files for analysis
- View total packet count and traffic size
- Analyze network protocols
- Visualize protocol distribution
- Explore source IP addresses
- View packet details and export results to CSV
- Dark-themed dashboard

## Technologies Used
- Python
- Streamlit
- Scapy
- Pandas
- Plotly

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal.

## Project Purpose
A Computer Networks mini-project demonstrating packet analysis and network traffic visualization.
